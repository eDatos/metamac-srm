# CLAUDE.md — METAMAC-SRM

METAMAC SRM (Structural Resources Manager) manages SDMX structural resources: codelists, concepts, categories, organisations, and Data Structure Definitions (DSDs). Multi-module Maven project with a Sculptor-based backend, GWT administrative UI, and external REST API.

**Main branch for PRs**: `develop`

## Module Architecture

- **metamac-srm-core**: Business logic, Sculptor domain entities, services, repositories
- **metamac-srm-web**: GWT-based administrative web application (WAR)
- **metamac-srm-rest-internal-impl**: Internal REST API (administrative)
- **metamac-srm-rest-external-impl**: External REST API (public read-only)
- **metamac-srm-external-web**: External REST API WAR
- **metamac-srm-soap-external-impl**: SDMX SOAP API

## Code Language

Always English: class names, methods, variables, constants, comments.

## Java 7 Restrictions

This is a legacy project. No Java 8+ constructs:
- No lambdas (` -> `), streams (`.stream()`), method references (`::`)
- No `Optional`, `LocalDate`, `LocalDateTime` — use Joda Time for dates
- Use traditional for-loops and null checks

Diamond `<>` inference:
- **Allowed** in backend/REST modules (core, rest-impl, external-web)
- **NOT allowed** in `metamac-srm-web` (GWT 2.x limitation)

## SLF4J — 3+ parameters

This SLF4J version only supports up to 2 inline parameters. For 3+, wrap in `new Object[]{}`:

```java
LOG.info("msg {}", p1);
LOG.info("msg {} {}", p1, p2);
LOG.info("msg {} {} {}", new Object[]{p1, p2, p3});
```

## i18n — .properties files

Always populate **three languages**: Catalan (`_ca`), Spanish (`_es`), English (`_en`). Default (`_default`) = same as English.

Always warn the user to review Catalan translations at https://www.softcatala.org/traductor/

### Catalan properties — apostrophe escaping

`MessageFormat.format()` treats `'` as an escape character (consumed, not displayed).
SRM has two notification paths with different rules:

| Key prefix | Processing path | Use |
|---|---|---|
| `notice_message.srm.message.*`, `notice_message.srm.exception.*`, `stream_message.srm.*` with `{N}` | CORE `NoticesRestInternalServiceImpl` → `MessageFormat.format()` | `''` |
| `notice_message.srm.action.*` (message body, no `{N}` params) | WEB `NoticesRestInternalFacadeImpl` → `LocaleUtil` only, no MF | `'` |
| `exception.srm.*` in `messages-srm*_ca.properties` | GWT Path B: `WebTranslateExceptions` → plain `String.replace()` | `'` |
| `info.srm.*` | Task-completion log, simple string replacement in GWT | `'` |
| `*Messages_ca.properties` in `src/main/java/` | GWT `@Messages` interface — MessageFormat always applied | `''` |

## Sculptor / Code generation (metamac-srm-core)

Entities, DTOs, service interfaces, and facade interfaces are **generated by Sculptor** from `.btdesign` files.
- **Never create entity classes or service interfaces manually**
- Generated code lives in `src/generated/` — do not modify
- Manual implementations and extensions go in `src/main/java/`

Key btdesign files:
- `src/main/resources/btdesign/metamac-srm-core-domain.btdesign` — entities + repositories
- `src/main/resources/btdesign/metamac-srm-core-dtos.btdesign` — DTOs
- `src/main/resources/btdesign/metamac-srm-core-facades.btdesign` — facade interfaces

After editing `.btdesign`, run `mvn generate-sources` in metamac-srm-core. Pattern:

| Artifact | Generated location | Manual location |
|---|---|---|
| Service interface | `src/generated/java/.../serviceapi/` | — |
| Service implementation | — | `src/main/java/.../serviceimpl/` |
| Facade interface | `src/generated/java/.../facade/` | — |
| Facade implementation | — | `src/main/java/.../facade/serviceimpl/` |

This module uses **Lombok** (`@Data`, `@EqualsAndHashCode`). Do not manually write getters/setters for annotated classes.

**Testing**: JUnit 4 + DBUnit fixtures in `src/test/resources/dbunit/` (XML). Tests extend `SrmBaseTest` and run in Spring transactions (auto-rollback). Mockito for unit tests without Spring context.

**External libraries**: `statistic-sdmx-srm-core` (base SDMX entity hierarchy) and `arte-fornax-cartridges-sculptor-framework` (Sculptor runtime, `ConditionalCriteria` query DSL). Read paths from `CLAUDE.local.md`.

## REST API (metamac-srm-external-web / metamac-srm-rest-external-impl)

**Apache CXF / JAX-RS** — NOT Spring MVC. Use JAX-RS annotations: `@Path`, `@GET`, `@PathParam`, `@QueryParam`, `@Produces`.

Always return `javax.ws.rs.core.Response`:
```java
return Response.ok(resource).build();
return Response.status(Status.NOT_FOUND).entity(error).build();
```

Always wrap endpoints in try-catch and delegate: `return RestExceptionUtils.manageException(e);`

**Facade / Mapper pattern**:
- Facade (`SrmRestExternalFacadeV10Impl`): receives REST params → calls service → calls mapper
- Do→REST mapper (e.g. `CodesDo2RestMapperV10`): domain entity → REST DTO — manual mapping, **not Dozer**
- Always pass `ServiceContext` with locale from `LocaleThreadLocal` to every service call

**API conventions**: versioned at `/v1.0/`; collections include `kind`, `total`, `limit`, `offset`, `selfLink`; standard query params: `query`, `limit`, `offset`, `orderBy`, `fields`.
